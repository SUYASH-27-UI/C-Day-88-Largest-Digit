# C Day 88 - Find the Largest Digit

## Description
This C program finds the largest digit in a positive integer.

## Example
**Input:** `5832`

**Output:** `Largest digit: 8`

## Concepts Used
- While Loop
- Modulus Operator
- If Statement
- Integer Division

## How to Run
1. Save the code as `largest_digit.c`.
2. Compile it using a C compiler.
3. Run the program and enter a positive number.
